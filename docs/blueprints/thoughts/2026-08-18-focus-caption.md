# Focus arrives with a caption; only a work has a door

> 2026-08-18 · **Status: in force** · Every focusable object gets one line when you arrive. Only the work can enter. The two instruments do not caption — playing them is the intro.

Converged 2026-08-18, after flying to the portrait felt empty: the camera got closer and
nothing else was said.

## The principle

**Arrival is a sentence. A door exists only where there is a work to enter.**

This sits on [`2026-08-18-portrait-focus.md`](2026-08-18-portrait-focus.md) rather than replacing
it. Click is still a camera move, not a minigame. The missing piece was meaning after the
flight, not a second verb per object.

It also answers, for this homepage, the open question in
[`2026-08-15-instrument-over-scene.md`](2026-08-15-instrument-over-scene.md) about navigation
inside the scene: the corner links stay; the one object that *is* a paper about a project may
also be a route into that project. The mug is not a route.

## Decided

**A one-line caption for every focusable object except the two instruments.** Mug, preprint,
flute, football, and the monitor pair. MPC and mixer stay mute — you are already playing them.

**Enter only on the work.** The preprint and the flute are one work (FlueBricks) and share a
door to `/projects/fluebricks`. Nothing else gets a fake door.

**Not a mode.** The caption belongs to the last object you flew to, and it recedes with the
same close/far distance already used to fade the page chrome. Clicking the desk clears it.
Orbiting does not invent a new caption.

**Look.** A pin on the object and a thin leader to the sentence in empty space — not a chip.
Settled 2026-08-18 from [`mockups/2026-08-18-focus-caption/`](../mockups/2026-08-18-focus-caption/index.html).

**DOM, not type in the Canvas.** No troika `Text`, no font fetch. The overlay stack already
owns the page's words.

## Still open

**The actual sentences.** Mechanism is decided; copy is not. One line each, in the site's
language, owned in one place so they cannot drift off the objects.

## What was rejected

**Caption only on the work** — flying to the mug would still be empty.
**A door on every object** — the mug is a portrait, not a page.
**Captioning the MPC and mixer** — the intro is that they play.
